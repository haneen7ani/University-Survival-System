# University-Survival-System


University Survival System is a mobile-first platform designed to help
university students manage their academic life and university services.

## Main Features

- Authentication & Onboarding
- Courses & Prerequisites
- GPA & Academic Progress
- Academic Registration
- Academic Results
- Academic Schedule
- Summer Courses
- Study Planner
- Deadlines & Notifications
- University Guide
- University FAQ
- Anime Gamification

## Actors

- Student
- Admin
