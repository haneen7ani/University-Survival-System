# User Stories

## 1. Authentication & Onboarding

As a student,
I want to create an account and select my university, faculty, department, and academic level,
so that the system can provide me with relevant academic information.

## 2. Courses & Prerequisites

As a student,
I want to view my courses and their prerequisites,
so that I know which courses I am eligible to take.

## 3. GPA & Academic Progress

As a student,
I want to calculate my GPA and track my academic progress,
so that I can understand my academic performance.

## 4. Academic Registration

As a student,
I want to register for eligible courses,
so that I can submit my academic registration request.

## 5. Academic Results

As a student,
I want to view my academic results,
so that I can track my grades.

## 6. Academic Schedule

As a student,
I want to view my academic schedule,
so that I know my classes, times, and locations.

## 7. Summer Courses

As a student,
I want to view available summer courses,
so that I can complete pending courses when possible.

## 8. Study Planner

As a student,
I want to create and manage study tasks,
so that I can organize my studying.

## 9. Deadlines & Notifications

As a student,
I want to receive notifications about important academic deadlines,
so that I do not miss them.

## 10. University Guide

As a student,
I want to search for university services and locations,
so that I can easily find the service I need.

## 11. University FAQ

As a student,
I want to search official university FAQs,
so that I can quickly find answers to common questions.

## 12. Anime Gamification

As a student,
I want to earn XP and complete quests,
so that I stay motivated while completing useful academic activities.
